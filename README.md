# GodotGame

Ce projet est un jeu fait à l'occasion d'un projet libre de ma formation, pour le décrire en quelques mots je dirais que "Slay the tower" est un jeu de tir et de plateforme en 2D avec un graphisme pixelisé. Le joueur devra passer 100 niveaux pour gagner tout en faisant des choix stratégiques, combattre des ennemis et esquiver des pièges.

pour pouvoir y jouer il faudra:
- installer Godot 4.x (version latest)
- une fois le logiciel lancer il faudra installer C# si ce n'est pas déja fait
- git clone le repo dans un dossier
- ouvrir le dossier depuis godot
- lancer une partie 😁
